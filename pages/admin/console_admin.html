🔥 สลับบัญชี Firebase

1️⃣ วิธีเอา Firebase Config:
1. เข้าเว็บ console.firebase.google.com ➔ เลือกโปรเจกต์
2. กดไอคอน ⚙️ Project Settings (ฟันเฟืองมุมซ้ายบน)
3. เลื่อนลงล่างสุดที่หัวข้อ "Your apps" ➔ เลือกเว็บแอป </>
4. คัดลอกโค้ดทั้งก้อน const firebaseConfig = { ... }; มาวางในกล่องด้านล่างได้เลย!
2️⃣ วิธีเอา Google Apps Script URL (Google Drive):
1. เปิดเว็บ script.google.com ➔ เปิดโปรเจกต์
2. กด Deploy (ขวาบน) ➔ Manage deployments
3. คัดลอก Web app URL มาใส่ในช่อง GAS URL (ถ้ามี)
💡 ดูคู่มือฉบับเต็มและตัวอย่างโครงสร้างไฟล์ได้ในโฟลเดอร์ _account_migration_kit/README.md
